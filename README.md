# TechHub Electronics – E-Commerce Web Application

## Project Overview

TechHub Electronics is an e-commerce web application for selling computer and electronic products online. The application allows customers to browse products, view product details, add products to a shopping cart, and complete a simulated checkout process.

The project is being developed as part of the **Getting Started in Web Programming (DLBITPEWP01_E)** course.

## Key Features

- Product catalogue
- Product detail pages
- Shopping cart
- Add, remove, and update cart items
- Automatic cart total calculation
- Checkout form
- Simulated order confirmation
- Responsive design for desktop, tablet, and mobile devices
- Product and order data stored in a PostgreSQL database
- JSON/API communication between the frontend and backend
- Asynchronous frontend-backend interaction

## Technology Stack

### Frontend
- React
- TypeScript
- Tailwind CSS

### Backend
- Python
- Django

### Database
- PostgreSQL

### Data Exchange
- JSON
- API / asynchronous requests

The main database entities are:

- Products
- Orders
- Order Items
